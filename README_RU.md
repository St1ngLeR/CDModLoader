# Crashday ModLoader
**ModLoader** - это ASI-плагин, который позволяет запускать игру с различными модификациями. Он значительно упрощает их установку, редактирование и удаление, не затрагивая при этом ни одного исходного файла игры.

## Установка и первый запуск

1. Перед началом работы с ModLoader убедитесь, что вы используете исполняемый файл игры Crashday версии **1.2**. Проверьте соответствие вашего файла следующим данным:

| Имя исполняемого файла | Версия игры | Размер файла (в байтах) | Контрольная сумма (CRC-32) | Контрольная сумма (MD-5) |
| --------------------- | ------------ | -------------------- | ----------------- | --------------- |
| Crashday.exe | 1.2 | 3378688 | 8D452A29 | F027022CF84FB0A7A9DB9770545346B9

2. Для работы ASI-плагина в игре необходимо использовать [Ultimate ASI Loader от ThirteenAG](https://github.com/ThirteenAG/Ultimate-ASI-Loader) (рекомендуется использовать 32-битную версию **dinput.dll**), поместив файлы плагина в корневую папку игры.
3. Запустите игру с установленным ModLoader, а затем закройте её. Если в директории игры появились файл `modloader.ini` и папка `modloader`, значит, ModLoader загружен и готов к работе.

## Установка модов

Чтобы установить моды, поместите каждый из них в отдельную папку внутри директории `modloader`. Вот и всё.

Например:
```
modloader/
└── awesome_mod/
    ├── trkdata/
    ├── textures/
    └── ...
└── yet_another_awesome_mod/
    ├── sounds/
    ├── editor/
    └── ...
```

## Удаление модов

Чтобы удалить модификации, просто удалите соответствующие им папки внутри `modloader`. Если вы хотите сохранить файлы модов, но временно ими не пользоваться, отключите их в настройках профиля (см. раздел [«Настройка профилей»](#настройка-профилей) ниже).

## Настройка ModLoader

Основные параметры находятся в файле `modloader.ini`, расположенном в той же папке, что и исполняемый файл игры.

- `Enabled` (по умолчанию `1`) - включение или отключение ModLoader без необходимости изменять его .asi-файл.
- `Log` (по умолчанию `0`) - включение или отключение создания лог-файла (журнала работы) ModLoader. Лог-файл может занимать много места, поэтому рекомендуется включать эту опцию только в том случае, если вы столкнулись с ошибкой, которую легко воспроизвести.
- `LoadAsiPlugins` (по умолчанию `1`) - включение или отключение загрузки ASI-плагинов. Это может быть полезно, если вы хотите запускать их независимо от среды ModLoader или если не доверяете конкретным плагинам.
- `Profile` (по умолчанию `default`) - название профиля, используемого при запуске.

## Настройка профилей

ModLoader загружает моды в игру с помощью профилей - наборов модификаций, выбранных и настроенных по усмотрению пользователя.

Если установлен хотя бы один мод, в папке `modloader/.profiles` создаются файлы для новых профилей. Каждый такой файл представляет собой INI-файл, названный в соответствии с именем профиля, заданным пользователем. Внутри файла профиля имеются два раздела: `[States]` и `[Priorities]`:
- Раздел `[States]` определяет, включен мод или выключен (используются значения `true` и `false` соответственно).
- Раздел `[Priorities]` задает порядок, в котором игра загружает моды. Это полезно, если вы хотите, чтобы один мод переопределял определенные элементы другого.

Пример:
```
[States]
CrashPatch=true
Widescreen Fix=true
Deathday=false
Jane's Mod=true
Default Nitro=true

[Priorities]
CrashPatch=50
Widescreen Fix=50
Deathday=50
Jane's Mod=50
Default Nitro=100
```

**Важно!** Если вы запускаете игру с выбранным профилем `default`, все новые моды будут включены автоматически. В других профилях моды по умолчанию отключены - это сделано для того, чтобы сохранить настройки, заданные пользователем для каждого конкретного профиля.

## Аргумент запуска для профилей модов

Чтобы не менять постоянно выбранный профиль в файле `modloader.ini`, можно запускать игру с нужным профилем через ярлык, используя аргумент `-modprof`.

Допустимы следующие форматы записи:
```
-modprof <profile_name>
-modprof "<profile_name>"
-modprof=<profile_name>
-modprof="<profile_name>"
```

Как уже упоминалось, если загрузчик обнаружит, что это новый профиль, он автоматически создаст соответствующий файл в папке профилей.

## Отдельные сохранения для каждого профиля модов

Чтобы избежать конфликтов в сохранениях, для каждого профиля предусмотрена собственная папка - это гарантирует, что профили остаются изолированными друг от друга.

Для всех профилей, кроме `default`, файлы сохранений находятся по пути `modloader/.savegames/<profile_name>`. Для профиля `default` путь остается прежним.

## Поддерживаемые типы файлов модов

| Тип файла  | Поддерживается? |
| ---------- | ------------- |
| Текстуры (.dds/.tga) | <p align=center>✅</p>
| 3D-модели (.p3d) | <p align=center>✅</p>
| Звуки (.wav) | <p align=center>✅</p>
| Музыка (.mp3/.ogg) | <p align=center>✅</p>
| Текстовые файлы (.cca/.lst/.txt/.cfl/...) | <p align=center>✅</p>
| Плагины (.asi) | <p align=center>✅*</p>

\* <small>ASI-плагины могут работать нестабильно, особенно если они взаимодействуют с файловой системой игры. Рекомендуется проверять стабильность каждого плагина отдельно.</small>

## Объединение категорий в редакторе трасс

Хотя новые файлы модов корректно работают через ModLoader, был предусмотрен механизм объединения новых категорий элементов редактора трасс (тайлов, контрольных точек, динамических объектов) со стандартными категориями, что обеспечивает их полноценную поддержку.

Для успешного объединения мод должен содержать файлы `fields.cat`, `dynobj.cat` или `cps.cat` в папке `trkdata/editor`. Внутри этих файлов категории должны быть настроены так же, как для использования в самой игре, но без включения стандартных категорий.

Пример - `awesome_mod/trkdata/editor/fields.cat`:
```
# Список категорий тайлов для редактора трасс Crashday
1						# Количество категорий

Next:						# Файл .cfl / Позиция X / Позиция Y / Поворот при отображении
My awesome tiles						# Название
3						# Количество объектов в категории
tile1.cfl 1 1 0 My awesome tile 1
tile2.cfl 2 1 0 My awesome tile 2
tile3.cfl 3 1 0 My awesome tile 3
```

Если всё сделано верно, то в редакторе трасс, помимо стандартных категорий, появятся новые категории из ваших модов.

Этот момент является необязательным: модификации для элементов трассы могут работать и без новых категорий, однако авторы этих модификаций не гарантируют их корректную работу, если категории не настроены.
